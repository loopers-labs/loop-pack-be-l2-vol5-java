## 유지하는 전제

논리 삭제, 브랜드·상품의 단일 트랜잭션, 재고 0인 상품 포함, 이미 삭제된 상품의 상태 유지,
다른 대상·과거 주문 보존은 요구사항이다. 실제 SQL 실행 뒤 전체 롤백을 검증한다.
브랜드 삭제와 상품 등록의 동시 실행은 이번 범위에서 제외한다.

## 구현 계획·검증으로 이어갈 것

- 삭제용 조회가 상품 전체를 제공하는지, 상품 ID 대응·매핑에 누락이 없는지 확인한다.
- 실제 변경 SQL 실행 뒤 실패시키고 트랜잭션 종료 후 재조회해 전체 롤백을 확인한다. 실패 주입 위치·방법은 구현 계획에서 정한다.

위 내용은 구현·검증 항목이며 추가 트레이드오프 문답을 요구하지 않는다.
서비스 분리와 배치 최적화는 필수 검토에서 제외한다. 기존 비교 기록은 보존하되 구체적인 필요가 생길 때만 다시 검토한다.
