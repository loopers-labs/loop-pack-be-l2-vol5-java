점수 계산과 고객 공개 / 검산과 고객 공개

계산 중에 고객이 조회하면 어느 랭킹을 볼까요?

고객은 요청한 주에 마지막으로 공개한 완성본을 봅니다. 새 판본의 검산이 끝나면 순위, 완성 기록, 조회할 판본을 가리키는 값이 한꺼번에 저장됩니다.

이 장의 용어

판본
같은 주의 랭킹을 새로 계산할 때 붙이는 번호입니다. 여기서 R1은 첫 판본, R2는 두 번째 판본입니다.
공개 포인터
고객 조회가 어떤 완성본을 읽을지 가리키는 DB 기록입니다.
트랜잭션
여러 DB 변경을 함께 확정하거나 함께 되돌리는 작업 단위입니다.

고객 응답이 빈 목록이면 아직 공개 전인가요?

주간 랭킹 API에서 첫 공개 전에는 상태가 NOT_PUBLISHED이고 스냅샷 ID가 비어 있습니다. 구매가 0건인 주도 계산을 마치면 상태가 PUBLISHED이고 스냅샷 ID가 있습니다. 두 응답 모두 목록은 비어 있습니다. 그림의 R1·R2는 내부 판본 표기이며, 고객 응답에는 스냅샷 ID가 제공됩니다.

구현과 검증 근거

  • 공개와 역순 완료를 검증한 주문 파티션 시험
  • 공개 중 저장 오류를 주입한 MySQL 시험
  • 빈 목록·공개 상태·스냅샷 ID를 비교한 고객 API 시험
