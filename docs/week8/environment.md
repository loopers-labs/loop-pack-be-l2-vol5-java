# 실행 환경 안내의 통합 위치

구현 전 환경 조사와 현재 운영 명령을 [API·운영 안내](completed/operations.md)로 통합했다.
JDK 21·Gradle 8.13, 서비스 포트와 제한 세션의 cache 대안은 [개발 환경과 제한 세션](completed/operations.md#개발-환경과-제한-세션)에 있다.

데이터 보존 실행·관리 포트 구분·DB 권한 조건은 같은 운영 안내를 따른다. 과거의 Docker 접근 실패를 현재 사용자 PowerShell의 상태로 간주하지 않는다.
실제 검증 상태는 [구현 현황](completed/README.md)에서 확인한다. 이 파일은 기존 참조를 위한 연결 문서다.
