# 8주차 · 쿠폰 발급과 인스턴스별 수용 제어

현재 구현과 검증을 찾는 시작점이다. C01~C06 기능이 커밋됐으며 아래 검증은 당시 실행 기록이다. 고객·관리자 HTTP와 독립 JVM 두 개의 대상 검증을 포함한다.
전체 검사에서 실패한 두 모듈은 Docker API 환경을 맞춘 재실행으로 해결했다. UP-TO-DATE 재사용을 포함한 최신 XML 635건은
실패·오류·skip 0이며, 단일 clean 실행 635건의 결과라는 뜻은 아니다. C06 기능은 b86c27c에 커밋됐다. 검사 수치는 2026-11-13 당시 근거이며 이번 문서 정리의 새 실행 결과가 아니다.

발급 결과의 원본은 DB이며, 쿠폰·슬롯·`issuedCount`를 같은 TX로 확정한다. 처리 자리는 인스턴스별 singleton
Java Semaphore가 담당한다. Redis는 확정 발급의 누적 집계이며 전역 수용·사용자 분산락에 사용하지 않는다.
기본 수용 상태는 닫힘이고, 기존 완료 결과와 본인 목록 조회는 신규 permit 없이 유지한다.

단계별 준비·진행 메모와 중복 제출 초안은 위 설계·구현 현황·검증·운영 문서로 통합했다.
로컬 인계는 선택적 재개 메모이며 Git에 포함하지 않는다. 실제 코드·현재 Git 상태를 함께 확인한다.
