# 초기 준비 기록의 통합 위치

쿠폰 미구현 시점의 일회성 준비 체크리스트는 종료했다. 당시 Git 기준점·준비 커밋과 사용자 JMeter baseline은
[초기 준비의 보존 기록](completed/README.md#초기-준비의-보존-기록)에 보존했다.

현재 실행 방법은 [운영 안내](completed/operations.md), 실제 완료 근거와 대기 항목은 [구현 현황](completed/README.md)을 따른다.
초기 cache·Docker 실패는 현재 기능의 실패나 아직 구현하지 않았다는 의미가 아니다. 이 경로는 기존 지침 참조를 위해 유지한다.
