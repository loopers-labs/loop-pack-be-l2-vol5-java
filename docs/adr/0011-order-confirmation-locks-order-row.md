# ADR 0011: 주문 확정은 주문 행을 잠그고 상태를 검사한다

Status: Accepted
Date: 2026-10-09

## Context

상품을 잠가도 먼저 읽은 주문의 DRAFT 상태는 오래된 값일 수 있다. 사고 흐름과 대안 비교는 [설계 2.3](../week3/design.md#23-같은-주문의-중복-확정)에 남긴다.

## Decision

주문 행을 `FOR UPDATE`로 읽은 뒤 소유자·상태를 판단한다. 앞 요청이 커밋하면 CONFIRMED를 거절하고 롤백하면 DRAFT를 다시 판단하는 흐름을 직접 표현하기 위해 선택했다. 완료된 본인 주문은 409이며 성공 응답 재사용·새 요청키는 추가하지 않는다.

## Alternatives and costs

DRAFT 조건부 UPDATE도 가능하지만 기존 JPA 객체와 갱신 결과를 맞춰야 한다. 낙관적 락도 가능하나 충돌 후 응답을 정해야 한다. 선택한 방식은 주문 트랜잭션 종료까지 같은 주문의 변경을 기다리게 한다.

검증 결과는 [구현 기록 2.3](../week3/implementation-log.md#23-같은-주문의-중복-확정), 전체 잠금 순서는 [설계 3.2](../week3/design.md#32-전체-잠금-순서와-대기-실패)에 둔다.
