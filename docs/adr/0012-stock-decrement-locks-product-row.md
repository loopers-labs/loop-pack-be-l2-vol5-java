# ADR 0012: 재고 차감은 상품 행을 비관적 락으로 보호한다

Status: Accepted
Date: 2026-10-09

## Context

처음에는 조건부 UPDATE로 재고를 안전하게 차감할 수 있다고 판단했다. 이후 기존 `Stock.decrease()`를 어떻게 활용할지도 비교했다. 실험과 사고 흐름은 [설계 2.1](../week3/design.md#21-재고-차감)에 남긴다.

## Decision

상품을 ID 순으로 잠근 뒤 기존 `Stock.decrease()`와 JPA 변경 저장을 유지한다. 잠금 후 읽은 값으로 사전 검사하고 Stock도 자신의 규칙을 검사한다. 현재 상품 UPDATE가 재고 컬럼을 포함하므로 관리자 수정·삭제·재고 설정도 잠금 조회한다.

## Alternatives and costs

조건부 UPDATE의 정확성을 부정한 선택은 아니다. SQL·객체 상태를 따로 관리하는 비용보다 기존 행동을 유지하는 쪽을 택했다. SQL의 동시성 방어와 객체의 규칙 검사를 함께 두는 설계도 가능하며, 규칙 중복만으로 조건부 UPDATE를 배제한 것은 아니다. 성능 우위를 입증한 선택도 아니다. 낙관적 락은 충돌 후 처리를 추가로 정해야 한다. 비관적 락은 대기·교착 가능성을 남기므로 범위와 순서를 관리해야 한다.
