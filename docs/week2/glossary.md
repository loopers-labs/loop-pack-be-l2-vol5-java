# commerce-api 용어집

[요구사항 문서](./requirements.md)에서 도출한 유비쿼터스 랭귀지다. 


| 용어    | 정의                                                                                           | 코드 이름                             | 출처                                                |
| ----- | -------------------------------------------------------------------------------------------- | --------------------------------- | ------------------------------------------------- |
| 고객    | 브랜드·상품을 조회하고 좋아요·포인트·주문을 이용하는 주체. 자신의 것만 다루며, 관리자 기능은 쓸 수 없다. 주문 맥락에서는 **구매자**로도 부르며 같은 대상이다 | `User`                            | R-ACCESS-01, R-ACCESS-03, R-ACCESS-04, R-ADMIN-10 |
| 브랜드   | 상품이 속하는 대상. 존재하며 삭제되지 않은 것만 상품이 참조할 수 있다                                                     | `Brand`                           | R-ADMIN-01, R-ADMIN-05, R-ADMIN-07                |
| 상품    | 이름·가격·소속 브랜드·재고를 갖고 주문에 사용되는 대상                                                              | `Product`                         | R-ADMIN-04, R-ADMIN-06, R-ORDER-01                |
| 재고    | 상품의 수량. 주문 확정으로만 차감되고 주문 생성으로는 차감되지 않는다                                                      | `Stock`                           | R-ADMIN-08, R-ORDER-04, R-ORDER-11                |
| 포인트   | 고객의 잔액. 1포인트는 1원이며 충전으로 늘고 주문 확정으로 차감된다                                                      | `Point`                           | R-POINT-01, R-POINT-03, R-ORDER-11                |
| 좋아요   | 고객이 상품에 등록하는 표시                                                                                | `Like`                            | R-LIKE-01, R-LIKE-04                              |
| 주문    | 여러 품목과 합계를 갖는 고객의 구매 요청. 확정할 때 잔액과 비교하는 **주문 금액**이 이 합계다                                                                      | `Order`                           | R-ORDER-01, R-ORDER-02, R-ORDER-09                            |
| 주문 품목 | 주문에 포함된 상품·수량·단가. 상품을 삭제해도 함께 삭제되지 않는다                                                       | `OrderItem`                       | R-ORDER-02, R-ADMIN-14                            |
| 결제 결과 | 확정에 성공한 주문이 남기는 결제액과 결과                                                                      | `PaymentResult`                   | R-ORDER-12, R-ORDER-14                            |
| 주문 상태 | 결제 전(`DRAFT`)과 결제 완료(`CONFIRMED`)                                                            | `OrderStatus`                     | R-ORDER-03, R-ORDER-12                            |
| `DRAFT`     | 결제 전 주문 상태. 재고와 포인트가 아직 차감되지 않았고 결제 결과가 없다                                       | `OrderStatus.DRAFT`     | R-ORDER-03, R-ORDER-04                            |
| `CONFIRMED` | 결제 완료 주문 상태. 재고와 포인트가 차감되었고 결제 결과를 갖는다                                              | `OrderStatus.CONFIRMED` | R-ORDER-11, R-ORDER-12                            |
