# commerce-api 용어집

[요구사항 문서](./requirements.md)에서 도출한 유비쿼터스 랭귀지다.


| 용어          | 정의                                                                                            | 코드 이름                                 |
| ----------- | --------------------------------------------------------------------------------------------- | ------------------------------------- |
| 고객          | 브랜드·상품을 조회하고 좋아요·포인트·주문을 이용하는 주체. 자신의 것만 다루며, 관리자 기능은 쓸 수 없다. 주문 맥락에서는 **구매자**로도 부르며 같은 대상이다  | `User`                                |
| 브랜드         | 상품이 속하는 대상. 존재하며 삭제되지 않은 것만 상품이 참조할 수 있다                                                      | `Brand`                               |
| 상품          | 이름·가격·소속 브랜드·재고를 갖고 주문에 사용되는 대상                                                               | `Product`                             |
| 재고          | 상품의 가용 수량. PG 결제에서는 예약 시 줄고 예약 확정 시 추가 차감되지 않는다. 포인트 결제에서는 주문 확정 시 차감된다. 주문 생성만으로는 변하지 않는다    | `Stock`                               |
| 포인트         | 고객의 잔액. 1포인트는 1원이며 충전으로 늘고 포인트 결제 시 차감된다. 신규 PG 주문에서는 사용하지 않는다                                | `Point`                               |
| 좋아요         | 고객이 상품에 등록하는 표시                                                                               | `Like`                                |
| 주문 | 품목 관리·최종 금액 결정·Payment 생성·주문 확정을 담당하는 애그리거트 루트. 주문 전체의 일관성을 책임진다. | `Order` |
| 주문 품목       | 주문에 포함된 상품·수량·단가. 상품을 삭제해도 함께 삭제되지 않는다                                                        | `OrderItem`                           |
| 결제 | 주문이 소유하는 결제 시도와 결과. 결제수단·금액·상태·시도 키·PG 식별자·발송 기록·성공 시각을 관리하며, 같은 결제 시도 재요청에는 같은 멱등키를 쓴다. PG 취소 결과가 미확정이면 `CANCEL_PROCESSING`, 취소가 확인되면 `CANCELED` 상태다. | `Payment` |
| 주문 상태 | 미확정 `DRAFT`, 결제 성공 반영 후 `CONFIRMED`. | `OrderStatus` |
| 재고 예약 | 주문 품목 수량만큼 재고를 확보하고 예약 상태는 `Order`가 관리하는 것. 가용 재고에서 제외되지만 판매 확정은 아니다. 예약 시작 후 품목 수량은 변경하지 않는다. | `Order` |
